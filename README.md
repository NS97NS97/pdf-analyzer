# Анализатор документов (Flask)

Локальный сайт, который собирает единый отчёт по всем PDF-файлам в выбранной
папке (включая вложенные папки): **название, автор, год, путь к статье**.
Результат можно открыть в Excel.

База данных и внешние API не используются — всё работает на вашем компьютере.

## Вариант 1. Готовая программа для Windows (Python не нужен)

Если вам нужен просто работающий инструмент — берите **`АнализаторPDF.exe`**
из папки `dist`. Он самодостаточный:

1. Скопируйте `АнализаторPDF.exe` на рабочий стол (или в любую папку).
2. Запустите двойным щелчком.
3. Откроется чёрное окно с надписью `Сайт открывается в браузере: …`
   и автоматически откроется браузер со страницей анализатора.
4. Работайте как обычно. Чтобы **завершить** программу, просто закройте
   чёрное окно.

Отчёты сохраняются рядом с `.exe` (файл `report.xlsx`).

Подходит для **64-разрядной Windows 10/11**. Python и установка чего-либо
на другом компьютере не требуются.

> Возможные предупреждения:
> * Windows SmartScreen может сказать «Неизвестный издатель» — нажмите
>   **Подробнее → Выполнить в любом случае** (файл не подписан сертификатом).
> * Антивирус иногда настороженно относится к файлам, собранным PyInstaller.
>   При необходимости добавьте файл в исключения.
> * При первом запуске программа распаковывается 3–5 секунд.

### Как собрать .exe самому

Нужен Python 3.8+ на компьютере, где вы собираете.

```bat
build_exe.bat
```

Скрипт сам установит PyInstaller и нужные библиотеки и положит готовый файл
в `dist\АнализаторPDF.exe`. Либо вручную:

```bat
pip install -r requirements-build.txt
py -m PyInstaller --noconfirm --clean --onefile ^
    --name "АнализаторPDF" ^
    --add-data "templates;templates" ^
    --add-data "static;static" ^
    --collect-submodules pypdf ^
    --exclude-module numpy --exclude-module pandas --exclude-module scipy ^
    --exclude-module matplotlib --exclude-module PIL ^
    app.py
```

## Вариант 2. Запуск из исходников (любая ОС)

Нужен Python 3.8+.

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python app.py
```

Затем откройте в браузере: <http://127.0.0.1:5000>

Если порт 5000 занят, укажите другой:

```bash
python app.py 5001
```

Если 5000 не занят, порт тоже подбирается автоматически. Чтобы при запуске
не открывался браузер, задайте переменную окружения `PDFANALYZER_NO_BROWSER=1`.


## Как пользоваться

1. Нажмите **«Задать путь к архиву»** — откроется системное окно Windows,
   в котором нужно выбрать папку. Путь подставится автоматически и анализ
   запустится сразу.
2. Результат появится в блоке **«Результат анализа папки»**.
3. В колонке **«Путь к статье»** путь — это ссылка: нажмите на неё, и PDF
   откроется в программе просмотра. Открывать можно только файлы из той
   папки, которую вы анализировали.
4. Нажмите **«Открыть xls»** — файл `report.xlsx` откроется в Excel
   (создаётся рядом с `app.py`).

Если системное окно выбора папки почему-то не открылось, путь можно ввести
вручную в появившемся поле.

## Структура проекта

```
app.py                  — сервер и логика анализа
templates/index.html    — страница сайта
static/style.css        — оформление
static/script.js        — кнопки и работа с таблицей
requirements.txt        — зависимости для запуска из исходников
requirements-build.txt  — зависимости для сборки .exe
build_exe.bat           — сборка автономного АнализаторPDF.exe
run_public.bat          — запуск сайта с публичной ссылкой (туннель)
dist/АнализаторPDF.exe  — готовая программа (появляется после сборки)
report.xlsx             — создаётся после анализа
```

## Как определяется название, автор и год

* **Название** — берётся из текста самой статьи (первые страницы PDF):
  обложки, названия издательств, институтов, адреса и служебные коды
  пропускаются, а само название собирается из нескольких строк, если оно
  напечатано в несколько строк. Название **не** берётся из имени файла.
* **Автор** — из свойств PDF, иначе по шаблонам вида «Иванов И. И.»,
  «И. И. Иванов», «Ivanov I. I.».
* **Год** — первое четырёхзначное число 19xx/20xx в тексте первых страниц.
* Если PDF — это **скан без текстового слоя** (или текст извлечён «сломанным»
  шрифтом), название и автор определить нельзя, в отчёте будет «—».
  Таких файлов немного; количество показывается в сообщении после анализа.
  Для них понадобилось бы OCR-распознавание (не входит в этот проект).

Автор и год в старых PDF тоже часто отсутствуют — «—» означает,
что данных в файле нет, а не ошибку.

## Размещение в интернете (pythonanywhere.com и подобные хостинги)

**Важно понимать:** этот сайт анализирует файлы, которые лежат
**на том компьютере, где он запущен**. Если выложить сайт на хостинг
(pythonanywhere и т. п.), он будет работать **на чужом удалённом сервере**,
а такой сервер **не имеет доступа к диску вашего компьютера**. Это не
ошибка программы, а защита браузера и операционной системы: ни один сайт
не может читать ваши локальные файлы и открывать на вашем ПК программы,
если он не запущен на вашем ПК.

Поэтому на хостинге принципиально **не работают**:

* выбор папки (ошибка `no display name` — у сервера нет рабочего стола);
* открытие PDF по ссылке из колонки «Путь к статье»;
* кнопка «Открыть xls» (Excel на сервере не запустится).

Сейчас в этом случае сайт не «падает», а показывает понятное
предупреждение и предлагает ввести путь вручную — но путь должен быть
на самом сервере, а файлы на сервере уже должны быть загружены.

### Что делать, чтобы сайт был доступен по ссылке И видел ваши файлы

Запускайте сайт **на своём компьютере** и открывайте его наружу через
«туннель» — тогда вся логика (выбор папки, открытие PDF и Excel) работает
как задумано, а у вас появляется публичный адрес.

1. Установите cloudflared: <https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>
2. Запустите сайт:
   ```bash
   python app.py
   ```
3. Во втором окне терминала поднимите туннель:
   ```bash
   cloudflared tunnel --url http://127.0.0.1:5000
   ```
4. cloudflared покажет ссылку вида `https://что-то.trycloudflare.com` —
   её можно открыть с любого устройства. Сервер по-прежнему работает на
   вашем компьютере, поэтому файлы остаются у вас и всё открывается локально.

Аналог: `ngrok http 5000` (требует регистрации).

То же самое можно сделать готовым файлом `run_public.bat` (Windows):
он запускает сайт и туннель одной командой (нужен установленный cloudflared).
